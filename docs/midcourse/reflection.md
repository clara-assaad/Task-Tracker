# Reflection

For this mid-course project, I used two AI tools: Claude AI and GitHub Copilot in VS Code.

I used Claude mainly during the planning stage. It helped me generate and refine the user stories for the two selected features, Due Date + Overdue Filter and Tags / Labels. I also used it to help create the Mini ADR. Claude was useful because it helped organize the requirements and suggest assumptions and alternatives. However, I still reviewed the output and reduced the scope when some suggestions were more complex than needed for this project.

I used GitHub Copilot mainly during implementation inside VS Code. It helped add the backend and frontend changes for both features and also helped create focused pytest tests. Most of the backend work was successful and worked well with the existing project. The test suite increased from 17 passing tests to 21 passing tests after the new features were added.

The main difficulty I had with AI was frontend CSS refinement. The functionality was already correct, but some Copilot CSS changes made the modal too large, caused scrolling problems, and changed the layout more than I wanted. Instead of continuing to accept AI changes, I reviewed the CSS manually and adjusted the modal size, spacing, padding, field heights, and layout until the form looked correct again.
