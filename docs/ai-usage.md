# My Personal AI Usage Rules

## Rule 1 - What I will never paste

I will never paste passwords, API keys, tokens, credentials, personal or confidential data, private production data, or code that I am not authorized to share into an AI tool.

## Rule 2 - What I will always verify before accepting

I will always review AI-generated code before accepting it, make sure I understand what it does, verify that it matches the project requirements, and test important behavior instead of assuming the AI output is correct.

## Rule 3 - How I will record AI contributions

I will document important AI contributions in the project when AI helps generate or significantly modify code, documentation, tests, configuration, or other project artifacts.
